🔍 技術說明

無需額外修改： L3 課程已經使用 type: 'interactive-quiz' 格式，PresentationLesson.vue 的 normalizeSlide 函數會自動處理此類型，將 questions 陣列拆分為獨立的 quiz 投影片。

L3 Quiz 格式

{
  type: 'interactive-quiz',
  title: '知識檢測：氣候變遷影響',
  questions: [
    {
      question: '波爾多氣候變暖的主要影響是...',
      options: ['A. ...', 'B. ...', 'C. ...', 'D. ...'],
      correct: 1,
      explanation: '詳細解析...'
    },
    // ... 更多題目
  ]
}

自動處理邏輯

case 'interactive-quiz': {
  if (Array.isArray(s.questions) && s.questions.length) {
    return s.questions.map((q, idx) => ({
      title: `${s.title} — 第 ${idx + 1} 題`,
      quiz: {
        question: q.question,
        options: q.options,
        correct: q.correct,
        explanation: q.explanation
      }
    }))
  }
}
