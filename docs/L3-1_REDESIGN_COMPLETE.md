## 課程結構

### 📊 第一章：氣候變遷的科學證據
**主題**: 數據、趨勢與觀測

**內容模塊**:
1. **溫度變化分析**
   - 50年溫度上升1.7°C的詳細數據
   - 生長季延長15-20天
   - 採收期提前13天
   - 極端天氣事件頻率增加

2. **數據可視化**
   - 1970-2020溫度趨勢圖表
   - 關鍵氣候指標對比表
   - 非線性加速特徵分析

3. **年份對比: 1982 vs 2020**
   - 經典年份與現代年份的6項關鍵指標對比
   - 氣候條件對葡萄酒風格的具體影響
   - 釀酒師面臨的新挑戰

4. **知識檢測**: 氣候數據測驗

### 🍇 第二章：對葡萄種植的多維影響
**主題**: 從葡萄園到酒杯的連鎖反應

**內容模塊**:
1. **葡萄生理變化**
   - 糖分累積加速（酒精度提升）
   - 酸度下降挑戰
   - 酚類成熟複雜性
   - 水分脅迫增加

2. **品種敏感度分析**
   - Cabernet Sauvignon: 中等敏感
   - Merlot: 高敏感
   - Cabernet Franc: 低-中敏感
   - Petit Verdot: 低敏感
   - 各品種適應策略

3. **知識檢測**: 葡萄生理影響測驗

### 🏰 第三章：頂級酒莊的創新應對
**主題**: 技術、管理與哲學的全方位革新

**內容模塊**:
1. **Château Margaux深度案例**
   - 葡萄園精細管理（遮陰、灌溉、葉幕）
   - 品種配比調整（CF↑, PV↑）
   - 採收時機優化（分批、夜間）
   - 釀造工藝創新（控溫、新桶比例）
   - 實施結果與成效評估
   - 前總經理Paul Pontallier名言

2. **多酒莊策略比較**
   - Château Latour: 科技驅動路徑
   - Château Palmer: 生物動力法路徑
   - Château Pontet-Canet: 有機與馬耕路徑
   - 不同理念的實踐與結果

### 🗺️ 第四章：產區格局的重新洗牌
**主題**: 贏家與輸家的分化

**內容模塊**:
1. **傳統產區挑戰與機遇**
   - **Médoc**: 雙刃劍效應（礫石優勢 vs 灌溉需求）
   - **Pomerol & Saint-Émilion**: Merlot挑戰（保水優勢 vs 過熟風險）
   - **Graves**: 穩定表現者（土壤多樣性）
   - **Entre-Deux-Mers**: 逆襲機會（成熟度改善）

2. **產區影響評估矩陣**
   - 6大產區的風險等級評估
   - 適應能力與未來展望
   - 投資決策參考

3. **知識檢測**: 產區影響測驗

### ♻️ 第五章：可持續發展的戰略轉型
**主題**: 從被動應對到主動建設

**內容模塊**:
1. **綠色革命**
   - 有機種植：3%→18%（2010-2023）
   - 碳中和2050目標與里程碑
   - 水資源精密管理
   - 生物多樣性恢復

2. **認證體系**
   - **HVE**: 入門級（60%滲透率）
   - **Agriculture Biologique (AB)**: 進階級（18%滲透率）
   - **Biodynamie (Demeter)**: 最高級（3%滲透率）
   - 各級別的要求、成本、市場價值

### 🔮 第六章：2050年波爾多的未來圖景
**主題**: 三種可能的發展路徑

**內容模塊**:
1. **三種情境預測**
   
   **🌿 樂觀情境：適應成功** (30%機率)
   - 溫度控制在+1.5°C
   - 傳統產區格局保持
   - 技術創新保持經典風格
   - 50%有機認證達成
   
   **⚡ 中等情境：深度調整** (50%機率)
   - 溫度上升+2-3°C
   - 產區格局重新洗牌
   - 品種結構重大調整
   - 風格向飽滿強勁演變
   
   **🔥 悲觀情境：系統性挑戰** (20%機率)
   - 溫度上升+3-4°C
   - 傳統產區格局崩潰
   - 品種徹底革命
   - 波爾多傳統風格難以為繼

2. **給不同參與者的行動建議**
   - 🍷 消費者：理解年份差異、支持可持續
   - 🏰 酒莊經營者：投資適應、轉型有機
   - 💼 投資者：重新評估產區風險
   - 📚 學習者：更新知識、系統思維

## 教學法特點

### 1. 漸進式深化
```
科學證據 → 具體影響 → 應對策略 → 格局變化 → 長期轉型 → 未來展望
  (知道)    (理解)      (分析)      (評估)      (綜合)      (創造)
```
遵循布魯姆教育目標分類法的認知層次

### 2. 多模態學習
- **視覺**: 圖表、數據表、矩陣
- **敘事**: 案例故事、酒莊實踐
- **互動**: 測驗、討論問題
- **反思**: 思考題、行動建議

### 3. 理論與實踐結合
- 每個理論點都有實際案例支持
- 抽象概念具體化（如風土與灌溉的矛盾）
- 提供可操作的行動路徑

### 4. 批判性思維培養
- 不迴避爭議（如terroir與技術的張力）
- 呈現多種觀點（樂觀vs悲觀情境）
- 鼓勵獨立思考（反思討論問題）
