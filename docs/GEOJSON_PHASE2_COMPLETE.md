## 已完成的短期優化項目

### 1. 產區標籤顯示 ✅

**功能描述**：
- 自動在地圖上顯示產區名稱標籤
- 標籤大小隨縮放級別自動調整
- 支援一鍵開關標籤顯示

**技術實現**：
```javascript
// Symbol 圖層配置
{
  id: 'aoc-label',
  type: 'symbol',
  layout: {
    'text-field': ['get', 'name'],
    'text-size': [
      'interpolate', ['linear'], ['zoom'],
      10, 12,  // zoom 10: 12px
      14, 16,  // zoom 14: 16px
      18, 20   // zoom 18: 20px
    ]
  }
}
```

**視覺效果**：
- 白色文字 + 黑色光暈（易於識別）
- 透明度隨縮放調整（10: 60% → 14: 90%）
- 智能防重疊（text-allow-overlap: false）

**控制方式**：
- 新增「顯示/隱藏標籤」按鈕（橙色）
- 快捷函數：`toggleLabels()`

### 2. 改進的工具提示系統 ✅

**功能描述**：
- 滑鼠懸停時即時顯示產區資訊
- 無需點擊即可快速預覽
- 平滑淡入淡出動畫

**顯示內容**：
- **產區名稱**（金黃色標題）
- **產區類型**（AOC 等級）
- **種植面積**（公頃）
- **提示文字**："點擊查看詳細資訊"

**技術實現**：
```javascript
// 動態定位工具提示
tooltipData.value = {
  visible: true,
  x: e.point.x + 15,  // 滑鼠右側 15px
  y: e.point.y - 10,  // 滑鼠上方 10px
  name: properties.name,
  info: props.regionInfo
}
```

**樣式設計**：
- 深黑背景（90% 不透明度）+ 毛玻璃效果
- 200ms 淡入動畫 + 向上滑動
- 指針穿透（pointer-events: none）

### 4. 3D 高度擠出效果 ✅

**功能描述**：
- 在 3D 模式下將產區以立體方式呈現
- 高度隨縮放級別動態調整
- 與地形數據完美融合

**技術實現**：
```javascript
{
  id: 'aoc-extrusion',
  type: 'fill-extrusion',
  paint: {
    'fill-extrusion-height': [
      'interpolate', ['linear'], ['zoom'],
      10, 0,      // zoom 10: 平面
      14, 500,    // zoom 14: 500米
      18, 1000    // zoom 18: 1000米
    ],
    'fill-extrusion-opacity': [
      'case',
      ['feature-state', 'hover'],
      0.9,  // 懸停: 90%
      0.7   // 正常: 70%
    ]
  }
}
```

**智能切換**：
- **3D 模式開啟**：
  - 顯示 `aoc-extrusion` 圖層
  - 隱藏 `aoc-fill` 圖層
  - 視角傾斜至 60°
  
- **3D 模式關閉**：
  - 隱藏 `aoc-extrusion` 圖層
  - 顯示 `aoc-fill` 圖層
  - 視角恢復水平

**交互增強**：
- 懸停高亮（不透明度提升）
- 點擊彈出詳細資訊
- 工具提示同步顯示

## 技術改進總結

### 圖層架構優化

**2D 模式圖層順序**：
1. `aoc-fill`（填充）
2. `aoc-outline`（邊框）
3. `aoc-label`（標籤）
4. `aoc-extrusion`（隱藏）

**3D 模式圖層順序**：
1. `aoc-fill`（隱藏）
2. `aoc-outline`（邊框）
3. `aoc-extrusion`（擠出）✨
4. `aoc-label`（標籤）

### 狀態管理增強

```javascript
// 新增響應式狀態
const labelsEnabled = ref(true)     // 標籤顯示
const legendVisible = ref(true)     // 圖例顯示
const tooltipData = ref({           // 工具提示數據
  visible: false,
  x: 0, y: 0,
  name: '', info: null
})
```

### 事件處理完善

**為 `aoc-extrusion` 圖層新增**：
- `mousemove` - 懸停高亮 + 工具提示
- `mouseleave` - 取消高亮 + 隱藏提示
- `mouseenter` - 指針變為 pointer
- `click` - 顯示詳細彈出窗口

## 性能優化措施

### 事件處理優化
- 使用 `map.off()` 避免重複監聽器
- Feature State API 提升渲染效率
- 工具提示定位計算簡化（僅 x/y 偏移）

### 圖層切換優化
- 智能顯示/隱藏（而非重建）
- 2D/3D 自動切換避免重疊
- 標籤可見性即時響應

### 資源複用
- GeoJSON 緩存機制持續有效
- 圖層設置只在創建時配置
- 樣式更新使用 `setPaintProperty`
