# L4 課程結構優化: 合併課程導讀與學習目標

## 📝 更新摘要
將 WSET Level 4 所有課程的「課程導讀」與「學習目標」合併為一張投影片,減少重複內容,優化學習體驗。

---

## 🎯 優化內容

### 修改前結構
```
1. 封面 (Cover) - 課程標題
2. 課程導讀 (Intro) - 課程簡介
3. 學習目標 (Objectives) - 目標列表  ⬅️ 與第2張重複
4. 第1章...
```

### 修改後結構
```
1. 封面 (Cover) - 課程標題
2. 課程導讀 (Intro) - 課程簡介 + 學習目標  ⬅️ 合併為一張
3. 第1章...
```

---

## 🔧 技術實現

### 1. 修改 `l4-shared.js`
**檔案位置**: `src/data/lessons/l4-shared.js`

**變更內容**:
- 移除獨立的 Objectives 投影片生成
- 將 `objectives` 數組整合到 `intro` 投影片的數據結構中

```javascript
// 修改前: 分別生成 Intro 和 Objectives
slides.push({ type: 'intro', ... })
slides.push({ type: 'objectives', objectives: objectives })

// 修改後: 合併到 Intro 中
slides.push({ 
  type: 'intro', 
  ...
  objectives: objectives  // 整合學習目標
})
```

### 2. 修改 `PresentationLesson.vue`
**檔案位置**: `src/components/PresentationLesson.vue`

**變更內容**:
- 增強 `intro` 類型的渲染邏輯
- 當 `intro` 包含 `objectives` 數組時,自動在課程導讀下方顯示學習目標
- 保留原有 `objectives` 類型以保持向後兼容性

**渲染邏輯**:
```javascript
case 'intro': {
  let content = `<p>${課程簡介}</p>`
  
  // 如果包含學習目標,一併顯示
  if (s.objectives && s.objectives.length > 0) {
    content += `
      <h3>📋 學習目標</h3>
      <ul class="objectives">
        ${學習目標列表}
      </ul>
    `
  }
  
  slide.content = content
}
```

## 🎓 設計理念

### 用戶體驗考量
1. **減少翻頁**: 相關資訊集中呈現
2. **邏輯連貫**: 「為什麼學」(導讀) + 「學什麼」(目標) 自然銜接
3. **視覺清晰**: 使用標題與圖標區分不同區塊

### 教學設計原則
- **簡潔性**: 避免內容重複
- **完整性**: 保留所有必要資訊
- **層次性**: 清晰的資訊架構
- **一致性**: 所有 L4 課程統一格式
