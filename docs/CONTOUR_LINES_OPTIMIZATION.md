## 🎯 問題描述
波爾多探索地圖的等高線條在 3D 地形視圖中看不清楚，需要調整顏色和樣式以提高可見度。

## 🔧 修改內容

### 檔案：`src/components/MapSection.vue`

#### 1️⃣ **等高線線條優化**（第 1315-1353 行）

**調整項目**：

| 項目 | 修改前 | 修改後 | 改善效果 |
|------|--------|--------|----------|
| **100m倍數線顏色** | `#FFD700`（金黃） | `#FFFF00`（亮黃） | ⬆️ 更醒目明亮 |
| **50m倍數線顏色** | `#FFAA00`（橙黃） | `#FFD700`（金黃） | ⬆️ 層次分明 |
| **一般線條顏色** | `#FF7733`（暗橙） | `#FFA500`（明亮橙） | ⬆️ 對比度提升 |
| **50m線寬度** | 0.9-3.0 | 1.5-4.5 | ⬆️ **+67% 更粗** |
| **一般線寬度** | 0.3-1.5 | 0.8-2.5 | ⬆️ **+167% 更粗** |
| **透明度（zoom 9）** | 0.4 | 0.7 | ⬆️ **+75% 更清晰** |
| **透明度（zoom 11）** | 0.6 | 0.85 | ⬆️ **+42%** |
| **透明度（zoom 13）** | 0.8 | 0.95 | ⬆️ **+19%** |
| **透明度（zoom 16）** | 0.9 | 1.0 | ⬆️ **完全不透明** |
| **模糊效果** | 無 | 0.5 | ✨ **新增柔和光暈** |

**修改程式碼**：
```javascript
'paint': {
  'line-color': [
    'case',
    ['==', ['%', ['to-number', ['get', 'ele']], 100], 0], '#FFFF00', // 亮黃色
    ['==', ['%', ['to-number', ['get', 'ele']], 50], 0], '#FFD700',  // 金黃色
    '#FFA500' // 明亮橙色
  ],
  'line-width': [
    'case',
    ['==', ['%', ['to-number', ['get', 'ele']], 50], 0],
    ['interpolate', ['linear'], ['zoom'], 9, 1.5, 11, 2.2, 13, 3.0, 16, 4.5], // 加粗
    ['interpolate', ['linear'], ['zoom'], 9, 0.8, 11, 1.2, 13, 1.8, 16, 2.5]  // 加粗
  ],
  'line-opacity': [
    'interpolate', ['linear'], ['zoom'],
    9, 0.7,   // 提高透明度
    11, 0.85,
    13, 0.95,
    16, 1.0
  ],
  'line-blur': 0.5 // 新增：輕微模糊效果
}
```

## 🎓 為什麼這些改善有效？

### 1️⃣ **顏色對比度**
- **修改前**：暗橙色 `#FF7733` 在深色衛星圖上對比度不足
- **修改後**：亮黃色 `#FFFF00` 和明亮橙 `#FFA500` 大幅提升對比度

### 2️⃣ **線條寬度**
- **修改前**：0.3-3.0px 太細，在 3D 地形上難以識別
- **修改後**：0.8-4.5px 增加 60-170%，清晰可見

### 3️⃣ **透明度優化**
- **修改前**：最低 40% 透明度導致線條過於模糊
- **修改後**：最低 70% 透明度，高縮放級別達到 100% 完全不透明

### 4️⃣ **模糊光暈**
- **新增**：`line-blur: 0.5` 產生柔和發光效果
- **效果**：線條邊緣發光，在深色背景上形成明顯輪廓

### 5️⃣ **標籤可讀性**
- **修改前**：字體小 (9-13px)、光暈弱 (2px)、金黃色不夠亮
- **修改後**：字體大 (10-15px)、光暈強 (2.5px)、亮黃色極醒目
