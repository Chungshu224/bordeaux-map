## 📚 詳細課程內容

### 1. 紅酒：波爾多的靈魂 🍷

#### AOC分級架構
```
🏆 村莊級AOC (Village AOC)
├── 左岸村莊：Pauillac、Margaux、St-Julien、St-Estèphe
├── 右岸村莊：St-Émilion、Pomerol
└── 特點：最高品質等級，嚴格產區規定

🥈 地區級AOC (Regional AOC) 
├── Haut-Médoc、Médoc、Graves、Pessac-Léognan
└── 特點：中等品質，較大產區範圍

🥉 基礎級AOC (Basic AOC)
├── Bordeaux、Bordeaux Supérieur、Côtes系列
└── 特點：入門等級，性價比導向
```

#### 風格差異分析
**左岸風格特徵：**
- 單寧強勁，酒體飽滿
- 黑醋栗、雪松、礦物質香氣
- 陳年潛力：10-30年或更長
- 適合正式晚宴、特殊慶祝

**右岸風格特徵：**
- 單寧柔順，質地絲滑  
- 櫻桃、李子、紫羅蘭香氣
- 陈年潜力：8-20年
- 適合日常品飲、休閒聚會

### 2. 白酒：被低估的珍寶 🤍

#### 乾白酒特色
**主要產區排名：**
1. **Pessac-Léognan** - 頂級乾白酒產區
2. **Graves** - 傳統白酒產區  
3. **Entre-Deux-Mers** - 清新易飲風格
4. **Blaye Côtes de Bordeaux** - 新興優質產區

**品種調配比例：**
- Sauvignon Blanc：60-80% (酸度和香氣)
- Sémillon：20-40% (酒體和複雜度)
- Muscadelle：0-10% (花香和果香)

**風味發展軌跡：**
- **年輕時：** 柑橘、熱帶水果、草本、礦物質
- **陳年後：** 蜂蜜、堅果、香料、礦物複雜度

#### 甜白酒奇蹟
**世界級產區：**
- **Sauternes** - 全球最著名甜酒產區
- **Barsac** - Sauternes內的精品子產區
- **其他產區** - Cadillac、Loupiac、Sainte-Croix-du-Mont

**貴腐菌作用過程：**
1. **感染階段** - 秋季晨霧提供理想濕度
2. **脫水濃縮** - 菌絲穿透，水分蒸發  
3. **風味轉化** - 產生蜂蜜、杏脯香氣
4. **分批採收** - 多次手工精選

**甜度分級：**
- **Moelleux（半甜）**：12-45 g/L，適合配餐
- **Liquoreux（極甜）**：45+ g/L，適合獨飲

### 3. 粉紅酒：夏日的優雅選擇 🌹

#### 釀造工藝對比
**🩸 放血法 (Saignée)**
- 紅酒釀造初期放出汁液
- 顏色較深，風味濃郁
- 主要使用Merlot、Cabernet Sauvignon

**🍇 直接壓榨法 (Direct Press)**
- 專門釀造粉紅酒
- 顏色較淡，風格清新
- 精確控制浸皮時間

#### 風味特徵與配餐
**香氣層次：**
- 紅果：草莓、覆盆子、櫻桃
- 花香：玫瑰花瓣、紫羅蘭
- 柑橘：粉紅葡萄柚、柳橙皮
- 草本：薄荷、羅勒

**理想配餐：**
- 海鮮類、家禽類、地中海沙拉
- 侍酒溫度：8-12°C
- 適合夏日聚會、戶外派對

### 4. 氣泡酒：現代創新的結晶 🥂

#### Crémant de Bordeaux規範
**品種限制：**
- 白葡萄：Sémillon、Sauvignon Blanc、Sauvignon Gris、Muscadelle
- 紅葡萄：Cabernet系列、Merlot、Malbec、Petit Verdot
- 紅葡萄比例不超過20%

**釀造標準：**
- 傳統香檳法（Méthode Champenoise）
- 最少12個月酒渣陳年
- 瓶中二次發酵產生氣泡

**市場定位：**
- 相比香檳具有優秀性價比
- 適合開胃酒、慶祝場合
- 清新爽脆，礦物感明顯

### 5. 酒標解讀：選酒的關鍵技能 🏷️

#### 必讀資訊解析
**🎯 產區標示層級：**
```
村莊級 > 地區級 > 基礎級
"Appellation [具體產區] Contrôlée"
```

**🏆 分級標示系統：**
- **1855分級：** Premier/Deuxième Grand Cru Classé
- **St-Émilion分級：** Premier Grand Cru Classé A/B
- **Cru Bourgeois：** Exceptionnel/Supérieur/基本

#### 實用選酒策略
**按預算分類：**
- **入門級 (€10-25)：** Bordeaux、Bordeaux Supérieur
- **中檔級 (€25-50)：** Cru Bourgeois、地區AOC
- **高檔級 (€50-150)：** 村莊AOC、分級酒莊  
- **收藏級 (€150+)：** 一二級酒莊、頂級年份

**按場合選擇：**
- **日常飲用：** 基礎AOC、年輕酒款
- **朋友聚餐：** 中檔村莊級、粉紅酒
- **正式晚宴：** 分級酒莊、陈年酒款
- **特殊慶祝：** 頂級年份、一級酒莊
