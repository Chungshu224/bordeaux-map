## 🎨 組件功能特色

### 互動功能

1. **自動播放動畫**
   - 組件載入後 0.5 秒自動播放
   - 5 層土壤依序展開（每層間隔 600ms）

2. **點擊互動**
   - 點擊任一土層顯示詳細資訊卡
   - 顯示：深度範圍、組成、功能、特性

3. **控制按鈕**
   - ▶ 播放動畫：重新播放展開動畫
   - 🔄 重置：清除狀態，重新繪製
   - 🌡️ 熱循環：展示白天/夜晚熱流動畫

### 教學重點

#### 📌 5 層 Pauillac 土壤結構（0-30米）

| 土層 | 深度範圍 | 主要組成 | 功能 |
|------|---------|---------|------|
| 1️⃣ 表層砂礫 | 0-2m | 砂礫 85% | 優異排水、熱儲存 |
| 2️⃣ 深層 Gunz 砂礫 | 2-10m | 古老砂礫 80% | 深層排水、礦物質來源 |
| 3️⃣ 過渡層 | 10-15m | 砂礫 60% + 黏土 30% | 緩衝層、養分交換 |
| 4️⃣ 深層砂礫 | 15-20m | 細砂礫 70% | 深層礦物質、根系支撐 |
| 5️⃣ 黏土基底 | 20-30m | 黏土 80% | 保水層、防止過度滲透 |

## 🚀 使用指南

### 教師教學流程

**步驟 1：啟動課程**
```
進入 L2-3 Pauillac 課程 → 第 5 個幻燈片
```

**步驟 2：展示功能**
1. 觀察自動播放動畫（土層依序展開）
2. 點擊 **表層砂礫**（0-2米）
   - 說明：85% 砂礫組成
   - 功能：優異排水、熱儲存、反射陽光
3. 點擊 **深層 Gunz 砂礫**（2-10米）
   - 說明：第四紀冰河期遺留
   - 強調：Pauillac 最核心的風土優勢
4. 啟用 **🌡️ 熱循環** 動畫
   - 展示白天太陽 → 向下熱流（紅色箭頭）
   - 展示夜晚月亮 → 向上冷流（藍色箭頭）
   - 解釋：砂礫的熱儲存與釋放機制

**步驟 3：重點強調**
- 🪨 **深度**：砂礫層可達 20 米，Médoc 最深厚
- 💧 **排水**：極佳排水性，葡萄根部不過濕
- 🌡️ **儲熱**：白天吸熱、夜晚釋放，幫助葡萄成熟
- 🌱 **貧瘠**：迫使根系深扎，吸收深層礦物質
- 🍇 **結果**：成就 Cabernet Sauvignon 的強勁結構與複雜度
