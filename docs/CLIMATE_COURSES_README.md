# 波爾多氣候與環境課程系統

## 新增功能概覽

已成功為波爾多葡萄酒學院增加了全面的氣候與環境課程系統，涵蓋WSET Level 1-3的不同深度內容。

## 課程架構

### Level 1 - 入門基礎
**課程 l1-2: 波爾多氣候與環境基礎** (18分鐘)
- 了解溫帶海洋性氣候特徵
- 認識Gironde河口與大西洋的調節作用
- 學習降雨、溫度對葡萄生長週期的影響
- 了解森林與水體對微氣候的影響
- 認識基本的地理環境要素

**主要內容章節：**
1. 地理位置與氣候類型
2. Gironde河口的調節作用
3. 年度氣候循環
4. 其他環境影響因素

### Level 2 - 中級進階
**課程 l2-5: 微氣候與風土條件深度分析** (28分鐘)
- 了解左岸與右岸的微氣候差異
- 學習坡向、海拔對葡萄園的影響
- 認識霜凍、冰雹等極端天氣風險
- 理解採收期選擇與氣候的關係
- 分析不同年份氣候對酒款品質的影響

**主要內容章節：**
1. 左岸右岸微氣候對比
2. 地形地貌的影響  
3. 極端天氣風險

### Level 3 - 高級專業
**課程 l3-1: 氣候變遷對波爾多的影響與應對** (35分鐘)
- 了解過去50年波爾多氣候變化趨勢
- 分析溫度上升對葡萄成熟期的影響
- 學習酒莊如何調整種植與釀造策略
- 探討新興產區的潛力與挑戰
- 理解可持續發展在現代葡萄酒業的重要性

**主要內容章節：**
1. 歷史氣候變化趨勢
2. 酒莊應對策略
3. 未來情景預測

## 互動元素

每個課程都包含豐富的互動元素：

### Level 1 互動元素
- `temperature-rainfall-chart`: 溫度與降雨量圖表
- `river-effect-simulator`: 河流效應模擬器
- `seasonal-changes-timeline`: 季節變化時間軸
- `environmental-factors-map`: 環境因素分佈地圖

### Level 2 互動元素  
- `bank-comparison-climate-map`: 左右岸氣候對比地圖
- `topography-3d-viewer`: 地形3D查看器
- `weather-risk-assessment-tool`: 天氣風險評估工具

### Level 3 互動元素
- `climate-trend-visualizer`: 氣候趨勢視覺化工具
- `adaptation-strategy-simulator`: 適應策略模擬器
- `future-scenario-explorer`: 未來情景探索器

## 使用方式

### 啟動學習模式
1. 在主畫面點擊「學習模式」按鈕
2. 選擇適合的WSET等級 (Level 1-3)
3. 瀏覽課程列表，選擇氣候與環境相關課程

### 課程學習體驗
1. **課程介紹**: 了解學習目標和預期時間
2. **理論學習**: 閱讀詳細內容和章節
3. **互動練習**: 使用地圖和模擬工具
4. **實踐應用**: 完成練習和案例分析
5. **評估測試**: 通過測驗檢驗學習成果

### 進度追蹤
- 學習目標完成狀態
- 互動活動完成情況  
- 測驗分數和通過狀態
- 整體課程進度百分比
