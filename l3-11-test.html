5. 專業品酒的技術要點與常見錯誤

🎯 專業品酒技術流程

溫度控制
  1. 紅酒：16-18°C
  2. 白酒：8-12°C
  3. 香檳：6-8°C
  4. 避免溫度波動
醒酒技術
  1. 年輕酒：1-2小時
  2. 老酒：30分鐘內
  3. 觀察顏色變化
  4. 香氣開放程度
品杯選擇
  1. 波爾多杯：結構型紅酒
  2. 勃艮第杯：細膩型紅酒
  3. 白酒杯：香氣集中
  4. ISO標準杯：專業品評
品評順序
  1. 由淡到濃
  2. 由乾到甜
  3. 由年輕到老
  4. 中途清潔口腔

  • B. 受心理暗示影響而失去客觀性
